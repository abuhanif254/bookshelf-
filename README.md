# Bookshelf — Buy & Download PDF Books Instantly

A high-performance digital bookstore built with **Next.js 15 App Router**, **TypeScript**, and **Tailwind CSS**.

## Features

- **Pixel-Perfect 1:1 Design**: Faithful reproduction with smooth animations and responsive layouts.
- **Dynamic Book Covers**: CSS-driven cover generation system with customizable color themes and geometric patterns.
- **Search & Advanced Filtering**: Live search dropdown suggestions, multi-category and price filters, rating filters, and custom sorting.
- **Product Details**: Comprehensive book pages with interactive tabs, look-inside previews, and reviews.
- **Shopping Cart & Wishlist**: Global React Context with real-time cart counts, quantity modification, and item persistence.
- **User Library**: Dedicated library dashboard to access and re-download purchased or free PDF books.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## Build for Production

```bash
npm run build
npm start
```
